# Beginner

Start here if you've never written C#, or never finished a course. By the end you'll be running real programs from `dotnet` projects, and you'll have built a command-line app that persists data to disk.

## Lessons

| # | Lesson | You'll learn |
| --- | --- | --- |
| 1 | [Setup & your first program](01-setup-and-first-program.md) | installing the .NET SDK, `dotnet run`, top-level statements, `Console`, scratch files |
| 2 | [Variables & types](02-variables-and-types.md) | `var`, `const`, `int` `double` `decimal` `string` `bool`, casts, `TryParse`, tuples |
| 3 | [Numbers & math](03-numbers-and-math.md) | integer division, `%`, overflow, `checked`, floating point, `decimal`, `Math`, `Random` |
| 4 | [Strings & characters](04-strings.md) | immutability, interpolation, ranges, `StringBuilder`, comparison, raw literals, Unicode |
| 5 | [Booleans & conditionals](05-booleans-and-conditionals.md) | comparisons, `&&`/`\|\|`/`!`, `if`, `switch` statements and expressions, patterns |
| 6 | [Loops](06-loops.md) | `for`, `foreach`, `while`, `do`/`while`, `break`/`continue`, reading input to the end |
| 7 | [Arrays & lists](07-arrays-and-lists.md) | arrays, `List<T>`, indexes and ranges, sorting, a first taste of LINQ, reference semantics |
| 8 | [Dictionaries & sets](08-dictionaries-and-sets.md) | key lookup, counting idiom, grouping, `HashSet<T>`, set algebra |
| 9 | [Methods](09-methods.md) | parameters, optional and named arguments, tuples, `out`/`ref`, `params`, local functions, recursion |
| 10 | [Nullable values](10-nullable.md) | `int?`, `string?`, `?.`, `??`, `??=`, nullable flow analysis, why `!` is dangerous |
| 11 | [Files & exceptions](11-files-and-exceptions.md) | `try`/`catch`/`finally`, `File`, `Path`, `using`, command-line arguments, exit codes |
| 12 | [Capstone: task tracker](12-capstone-task-tracker.md) | put it all together in a real CLI app |

## How to work through it

- One lesson per sitting. Type every example. Do the exercises.
- Don't move on until the "Recap" all makes sense.
- Stuck? Re-read the "Common mistakes" section. Your bug is probably there.

## When you're done

You should be able to explain every line of the capstone and add a new feature to it unaided. Then go to [Intermediate](../intermediate/index.md).
