# csharp-course

A complete, self-paced C# curriculum in Markdown: 36 lessons across Beginner, Intermediate and Advanced, each level ending in a capstone project.

**Read it online:** https://hunterghall.github.io/csharp-course/

The buildable source of the three capstones lives in [`capstones/`](capstones) (task tracker, Markdown link checker, parallel file indexer) and is built and tested by CI on Linux, Windows and macOS.

To preview the site locally:

```bash
pip install mkdocs-material
mkdocs serve
```
